# Session 5.2 — Timed Scoring System

## Goal

Add a 2-minute countdown timer and a real scoring formula to `GameController`, replacing the plain "moves" counter as the primary metric, and surface a "perfect match" streak bonus popup.

## Depends on

Session 5 (`GameController`), session 5.1 (`GameSession`/setup flow — need the chosen level and player name to eventually save a score).

## Scoring rules

- **Timer**: fixed 2:00 (120s) countdown per game, starts on game start (or on first flip — pick first flip so idle time on a freshly-dealt board doesn't burn the clock; note the choice in code comments). Reaching 0:00 before all pairs are matched ends the game as a **timeout/game-over** (distinct from a win) — score still counts whatever was earned so far.
- **Base points per match**: on every successful pair match, award `10 + secondsRemaining` (secondsRemaining = whole seconds left on the clock at the moment of that match). This makes early/fast matches worth more and naturally tapers as time runs down.
- **Streak bonus**: track `currentStreak`, incrementing by 1 on every successful match and resetting to 0 on every mismatch. When a match occurs with `currentStreak >= 2` (i.e. this is at least the 2nd consecutive match with no intervening mismatch), award an additional flat bonus (constant `STREAK_BONUS_POINTS = 5`, kept as a named constant so it's easy to tune later) on top of the base match points.
- **Total score** = running sum of all base match points + all streak bonuses earned. No penalty for mismatches beyond resetting the streak (moves count can still be tracked internally/shown in HUD, but score itself isn't reduced by mismatches).
- **Win vs. timeout**: win = all pairs matched with time remaining (final score = accumulated score, plus consider a flat "time remaining" completion bonus — keep optional/simple, e.g. none for now, accumulated match scoring already rewards speed). Timeout = clock hits 0 with unmatched pairs remaining; game ends immediately, whatever score was accumulated is final.

## Tasks

- Extend `GameController` (or a small companion `ScoreController`/`Timer` module kept separate for clarity — recommended split: `src/game/Timer.js` for the countdown, `src/game/ScoreController.js` for score/streak math, both composed into `GameController`):
  - `Timer`: `start()`, `pause()`/`stop()`, `getSecondsRemaining()`, emits `onTick(secondsRemaining)` and `onTimeout()`.
  - `ScoreController`: `recordMatch(secondsRemaining)` → computes base + streak bonus, updates `score`, updates `currentStreak`, returns `{ basePoints, streakBonus, totalAwarded }` for that match so the UI can react. `recordMismatch()` → resets `currentStreak` to 0.
  - Wire into the existing match/mismatch branches in `GameController` from session 5: on match, call `Timer.getSecondsRemaining()` → `ScoreController.recordMatch(...)` → emit an event (e.g. `onScoreChange(score, matchBreakdown)`) so the UI (session 7) can update the score display and show the bonus popup.
  - On `Timer.onTimeout()`, if the game isn't already won, force a "game over" state (lock input, emit `onTimeout`/reuse `onWin`-style event with a `won: false` flag) so downstream code (leaderboard save in session 7) can distinguish a win from a timeout.
- Bonus popup contract: emit enough data (e.g. `{ streakBonus: 5 }`) that the UI layer can render **"Bonus perfect match +5 pts!"** (or whatever `STREAK_BONUS_POINTS` currently is — the `+x` should always reflect the live constant, not a hardcoded string) briefly near the matched cards or in the HUD, auto-dismissing after ~1–1.5s. Only fire this event when a streak bonus was actually awarded (i.e. skip on the very first match of a streak, where there's no bonus yet).

## Done when

- Starting a game counts down from 2:00, visibly reaches 0 and triggers a timeout/game-over path distinct from a win if pairs remain unmatched.
- Matching pairs correctly awards `10 + secondsRemaining` each time (verify via console logging of computed scores against the clock at match time).
- Three or more consecutive matches with no mismatch in between correctly trigger the streak bonus from the 2nd consecutive match onward, and a single mismatch resets the streak so the next match after it does *not* get a bonus.
- Emitted events carry enough data for a future UI (session 7) to render the running score and a "Bonus perfect match +5 pts!"-style popup without recomputing scoring logic itself.
