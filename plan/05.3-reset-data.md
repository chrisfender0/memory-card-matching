# Session 5.3 — Reset Data Button

## Goal

Add a "Reset Data" control to the landing page that wipes all game-related `localStorage` data (leaderboard, last-used name, anything else added later), with a confirmation step so it can't be triggered by accident.

## Depends on

Session 5.1 (`src/storage/leaderboard.js`, landing page).

## Tasks

- Extend `src/storage/leaderboard.js` (or add a small `src/storage/reset.js`) with a `resetAllData()` function. Prefer an explicit list of known keys (`mcm.leaderboard`, `mcm.lastName`, plus any added by later sessions) over a blanket `localStorage.clear()`, so the reset stays scoped to this game even if the page ever shares an origin with other stored data. Keep the key list in one place (e.g. exported `STORAGE_KEYS` array from the storage module) so new keys added later are easy to include.
- Landing page UI: small, visually de-emphasized "Reset Data" button/link at the bottom of the screen (not styled like the primary Play button — this is a destructive, rarely-used action).
- Confirmation: tapping Reset Data shows a lightweight confirm step before wiping anything — either a native `confirm()` dialog (simplest, zero extra markup) or a small custom confirm overlay ("This will erase your leaderboard and saved name. Reset?" / Cancel / Reset) if native dialogs feel out of place on mobile. Either is acceptable; custom overlay preferred for visual consistency with the rest of the UI if time allows.
- On confirmed reset: call `resetAllData()`, then re-render the landing page's leaderboard section immediately (should now show the empty state), and clear the prefilled name field state so a subsequent Play → Setup shows an empty name input.

## Files touched

`src/storage/leaderboard.js` (updated: `STORAGE_KEYS`, `resetAllData()`), `src/ui/screens/Landing.js` (button + confirm + re-render), `src/style.css` (button styling).

## Done when

- Tapping Reset Data prompts for confirmation and does nothing if cancelled.
- Confirming clears all known game `localStorage` keys, the landing page immediately reflects an empty leaderboard, and reloading the page confirms the data is actually gone (not just hidden in memory).
- Starting a new game after a reset shows an empty name field on the setup page (no stale last-used name).
