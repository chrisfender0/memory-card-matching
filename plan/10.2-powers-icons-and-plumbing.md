# Session 10.2 — Power Icons & Shared Plumbing

## Goal

Generate the 6 power icons, populate the registry with real entries, and build the shared infrastructure every individual power (sessions 10.2.1–10.2.6) will need. This session ships no power *behavior* itself — it's the foundation the six power-specific sessions build on.

## Depends on

Session 10 (`PowerBase`, `NoOpPower`, `registry.js`, hook call sites, `mismatchStreak`, `cardMismatchCounts`), session 10.1 (selector UI consuming `POWERS`), session 5.2 (`Timer`, `ScoreController`), session 5.4 (match/explode animation and lock timing), session 4 (`Board`), session 3 (`Card`).

## Icons

- `src/assets/powerIcons.js`, mirroring session 2's `cardArt.js` approach: draw each icon procedurally on an off-screen canvas (gradients/shapes, no external image files), output as a `dataURL` (`canvas.toDataURL()`) or reusable `<canvas>` element — these render in the DOM carousel (10.1), not the three.js scene.
- One glyph per power, badge-style (circular background in a themed color + a simple centered icon shape), ~128×128:
  - **Telepathy** — purple background, concentric rings or a stylized eye.
  - **Time Traveler** — teal/blue background, hourglass or clock-with-arrow.
  - **Luck of the Draw** — green background, four-leaf clover or a die face.
  - **Cold as Ice** — ice-blue background, snowflake.
  - **Touch of Death** — dark red/black background, skull or skeletal hand.
  - **Greasy Fingers** — amber/yellow background, fingerprint or smudge swirl.
- `generatePowerIcon(id)` → returns the drawn asset; cache like session 2 did (generate once, reuse).

## Registry

Populate `POWERS` in `src/game/powers/registry.js` with 6 entries: `{ id, name, description, icon }`. Description copy (kept short enough for the 10.1 carousel):

- Telepathy — "After 3 mismatches, your next flip reveals its match with a purple glow — but that match is worth half points."
- Time Traveler — "Every match adds 5 seconds to the clock. 3 mismatches in a row costs you 2 seconds."
- Luck of the Draw — "Random flips sometimes auto-match. 5 mismatches in a row deals 2 fresh pairs onto the board."
- Cold as Ice — "After 3 mismatches, your next flip freezes face-up until matched. Wait too long and a second card freezes too."
- Touch of Death — "Mismatch the same card twice and it auto-matches. Do it 3 times total, or twice in a row, and you instantly lose."
- Greasy Fingers — "Matching a pair sometimes flips another card for a 1-second peek — but not twice without a match in between."

Leave each power's actual class as `NoOpPower` (from session 10) until its dedicated session lands — the registry entry existing with real copy/icon doesn't require the behavior to exist yet, so this session is safe to ship standalone and playtest the selector fully before any power does anything.

## Shared plumbing (used by 10.2.1–10.2.6)

- **Score multiplier hook**: `ScoreController.recordMatch(secondsRemaining, options)` gains an optional `{ multiplier: 0.5 }`-style param (default 1), applied to both base points and streak bonus. (Needed by Telepathy.)
- **Timer adjustment hook**: `Timer.addSeconds(n)` (positive or negative), clamped so it can't push the clock negative or (if you want a sane ceiling) above some max like 5:00. (Needed by Time Traveler.)
- **Board pair-injection hook**: `Board.addPairs(n)` — pulls `n` unused face ids from the 32-pool if available for the current level (or reuses ones already in play if the pool is exhausted, e.g. on hard mode), spawns the new face-down pairs into the layout, and re-flows/re-scales the grid (reuse session 4's `layout()` sizing logic) without disturbing already-matched (removed) or currently-frozen cards' positions any more than necessary. (Needed by Luck of the Draw — budget extra time here, it's the trickiest new piece of infra in the whole powers arc.)
- **Frozen card state**: `Card` gains a `frozen` flag; when true, the card stays face-up and is excluded from the normal mismatch-flip-back timer, but remains clickable/targetable for matching. `Board`/`GameController` must skip auto-hiding frozen cards during mismatch resolution. (Needed by Cold as Ice.)
- **Forced-loss path**: `GameController` gains a way to immediately end the game as a loss (distinct from the session 5.2 timeout path) — locks input, sets final score to 0, and routes to the same game-over/leaderboard flow a timeout uses. Session 7's win/game-over screen should treat "loss" generically (a `won: false` result with a reason) rather than assuming timeout is the only non-win ending. (Needed by Touch of Death.)

None of Time Traveler, Luck of the Draw, Cold as Ice, or Touch of Death's specific *logic* is implemented here — only the shared primitives they'll call.

## Done when

- All 6 icons render distinctly and legibly in the 10.1 carousel, each with correct name/description copy.
- Selecting any power still plays a completely normal game (since each is still `NoOpPower` under the hood) — confirms the registry/copy work is decoupled from behavior.
- `ScoreController.recordMatch(secondsRemaining, { multiplier: 0.5 })` halves points correctly in isolation (unit-test or console-verify).
- `Timer.addSeconds(5)` and `Timer.addSeconds(-3)` correctly adjust the visible countdown and respect clamping.
- `Board.addPairs(2)` correctly injects 2 new face-down pairs into a live board and re-lays-out the grid without displacing matched/removed cards, tested on at least one level size.
- Setting `card.frozen = true` on a face-down-flip-then-mismatch card correctly leaves it face-up and un-flippable-back during a manual test.
- A manually triggered forced-loss call correctly locks input, zeroes the score, and reaches the game-over/leaderboard flow.
