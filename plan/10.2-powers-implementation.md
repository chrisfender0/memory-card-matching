# Session 10.2 — Power Icons & Implementations

## Goal

Generate the 6 power icons and implement all 6 powers against the hook architecture from session 10, populating `registry.js` for real. This is the largest session in the plan — if it feels too big for one sitting, it's safe to split by power (each power's subsection below is close to independent) rather than push through all 6 at once.

## Depends on

Session 10 (`PowerBase`, `NoOpPower`, `registry.js`, `mismatchStreak`, `cardMismatchCounts`, hook call sites), session 10.1 (selector UI consuming `POWERS`), session 5.2 (`Timer`, `ScoreController`), session 5.4 (match/explode animation and its lock timing), session 4 (`Board`).

## Icons

- `src/assets/powerIcons.js`, mirroring the approach from session 2's `cardArt.js`: draw each icon procedurally on an off-screen canvas (gradients/shapes, no external image files), but output as a `dataURL` (`canvas.toDataURL()`) or a reusable `<canvas>` element rather than a `THREE.CanvasTexture` — these render in the DOM carousel (10.1), not in the three.js scene.
- One glyph per power, badge-style (circular background in a themed color + a simple centered icon shape), ~128×128:
  - **Telepathy** — purple background, concentric rings or a stylized eye.
  - **Time Traveler** — teal/blue background, hourglass or clock-with-arrow.
  - **Luck of the Draw** — green background, four-leaf clover or a die face.
  - **Cold as Ice** — ice-blue background, snowflake.
  - **Touch of Death** — dark red/black background, skull or skeletal hand.
  - **Greasy Fingers** — amber/yellow background, fingerprint or smudge swirl.
- `generatePowerIcon(id)` → returns the drawn asset; cache like session 2 did (generate once, reuse).

## Registry

Populate `POWERS` in `src/game/powers/registry.js` with 6 entries: `{ id, name, description, icon }`, description text matching the ability text below (kept short enough to read in the 10.1 carousel).

## Shared plumbing needed beyond session 10

- **Score multiplier hook**: `ScoreController.recordMatch(secondsRemaining, options)` needs an optional `{ multiplier: 0.5 }`-style param (default 1) so Telepathy can halve points for an assisted match without every other power needing to know about it.
- **Timer adjustment hook**: `Timer` needs an `addSeconds(n)` method (positive or negative) for Time Traveler.
- **Board pair-injection hook**: `Board` needs an `addPairs(n)` method that pulls `n` unused face ids from the 32-pool (if available for the current level) or reuses ones already in play, spawns the new face-down pairs into the layout, and re-flows/re-scales the grid (reuse session 4's `layout()` sizing logic) without disturbing already-matched (removed) or currently-frozen cards' positions any more than necessary. This is the trickiest new piece of infra in this session — budget extra time for it if implementing Luck of the Draw.
- **Frozen card state**: `Card` needs a `frozen` flag; when true, the card stays face-up and is excluded from the normal mismatch-flip-back timer, but remains clickable/targetable for matching. `Board`/`GameController` need to skip auto-hiding frozen cards during mismatch resolution.
- **Game-over-with-zero-score path**: `GameController` needs a way to force an immediate loss (distinct from the timeout path from 5.2) — freeze input, set final score to 0, and route to a game-over/leaderboard flow the same way a timeout does (session 7 should treat "loss" states generically rather than assuming timeout is the only non-win ending).

## Powers

### 1. Telepathy

- Trigger: `mismatchStreak` (from session 10) reaches 3 → arm a one-shot flag, e.g. `telepathyCharged = true`, and reset `mismatchStreak` to 0 (needs 3 fresh mismatches to recharge).
- Effect: on the next `onFlipFirstCard(card, ctx)` while charged, find that card's matching partner still on the board and apply a temporary purple highlight/outline to it (a few seconds, or until the turn resolves) via a material emissive tint or an outline mesh. Consume the charge (`telepathyCharged = false`).
- Scoring: if that assisted pair is completed as a match (whether immediately or later, while still highlighted or even after — keep it simple and mark the *card* as "telepathy-flagged" until it's matched), award that match at **50% points** via `ScoreController.recordMatch(secondsRemaining, { multiplier: 0.5 })`. Streak bonus (if otherwise applicable) is also halved as part of the same multiplier application.
- Edge case: if the flagged partner card gets matched via a completely unrelated pairing attempt before the player acts on the highlight, still apply the 50% multiplier (the discount is tied to the *card*, not the specific turn).

### 2. Time Traveler

- On every confirmed match (`onMatch`): `Timer.addSeconds(5)`.
- Trigger: `mismatchStreak` reaches 3 → `Timer.addSeconds(2)`, then reset `mismatchStreak` to 0 (so it can trigger again after 3 more consecutive mismatches).
- No scoring changes — purely timer manipulation.

### 3. Luck of the Draw

- On every `onFlipFirstCard`: roll a small random chance (named constant, e.g. `LUCK_TRIGGER_CHANCE = 0.08`) — if it hits, treat this as an **automatic match**: locate the flipped card's partner, flip both up, run the normal match flow (session 5.4 animation, session 5.2 scoring at full value) without requiring a second manual pick. Skip the normal "first pick, wait for second pick" turn structure for this turn.
- Trigger: `mismatchStreak` reaches 5 → call `Board.addPairs(2)` (see shared plumbing above) to inject 2 new pairs into the active board, then reset `mismatchStreak` to 0.
- Edge case: guard against auto-match triggering on a card that has no remaining partner on the board (shouldn't happen under normal play, but check before acting).

### 4. Cold as Ice

- Trigger: `mismatchStreak` reaches 3 → arm `coldCharged = true` and reset `mismatchStreak` to 0.
- Effect: on the next `onFlipFirstCard` while charged, mark that card `frozen = true` (stays face-up permanently, skips mismatch-flip-back) and consume the charge. Track `turnsSinceFreeze = 0` for this frozen card, incrementing on each subsequent turn resolution (`onTurnResolved`) while it's still unmatched.
- Escalation: if `turnsSinceFreeze` exceeds 3 turns without that frozen card being matched, freeze one additional random still-face-down, unmatched card (`frozen = true`) as well.
- Frozen cards stop counting toward `turnsSinceFreeze` once matched (normal match flow applies to them otherwise — scoring unaffected, this power only changes visibility/flip-back behavior).

### 5. Touch of Death

- Track per-card mismatch counts via the shared `cardMismatchCounts` (session 10). When any single card's count reaches 2 (i.e., it's been on the losing end of a mismatch twice), trigger **touch of death** for that card: force-match it with its real partner immediately (auto-reveal partner, run match flow), regardless of what it was actually paired with on the flip that triggered this.
- Track `touchOfDeathCount` (total invocations this game) and whether the *previous* turn also invoked touch of death (`lastTurnWasTouchOfDeath`).
- Instant loss condition: if touch of death triggers twice **back-to-back** (this turn and the immediately preceding turn both invoked it), or if `touchOfDeathCount` reaches 3 total in the game (regardless of spacing), immediately end the game as a loss with **score forced to 0** (use the shared "force game over" hook from the plumbing section above).
- Scoring: a touch-of-death auto-match itself still awards normal match points via the usual flow (unless the loss condition above fires in the same instant, in which case the loss overrides — final score is 0 either way).

### 6. Greasy Fingers

- On every confirmed match (`onMatch`), if not on cooldown, roll a chance (named constant, e.g. `GREASY_TRIGGER_CHANCE = 0.25`) to trigger a "peek": randomly pick another face-down, unmatched card and flip it face-up temporarily for 1 second, then flip it back down (no scoring/state effect — pure information bonus for the player).
- Cooldown: once a peek triggers, set `greasyOnCooldown = true`; it cannot trigger again until the *next* successful match happens (clear the cooldown flag at the start of the next `onMatch` check, before rolling), enforcing "sometimes greasy fingers can't flip a card until another pair is matched."
- No interaction with scoring or the match's own animation/lock timing beyond the temporary extra flip (make sure the 1s peek doesn't interfere with the mismatch/match lock state from sessions 5/5.4 — treat it as a purely visual aside that doesn't hold up turn progression).
