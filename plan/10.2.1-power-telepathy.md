# Session 10.2.1 — Power: Telepathy

## Goal

Implement the Telepathy power: after 3 consecutive mismatches, the next flipped card's real match gets highlighted on the board — at the cost of half points if that match is completed.

## Depends on

Session 10 (`PowerBase`, hook call sites, `mismatchStreak`), session 10.2 (registry entry + icon already exist, plus the score multiplier hook on `ScoreController.recordMatch`).

## Spec

- **Trigger**: `mismatchStreak` (shared tracker from session 10) reaching 3 arms a one-shot flag, e.g. `telepathyCharged = true`, and resets `mismatchStreak` to 0 (so it takes 3 fresh consecutive mismatches to recharge again).
- **Effect**: on the next `onFlipFirstCard(card, ctx)` while charged, find that card's matching partner still face-down on the board and apply a temporary purple highlight/outline to it (emissive tint or an outline mesh works — reuse whatever visual technique feels consistent with existing card materials). Consume the charge immediately (`telepathyCharged = false`) so this only ever affects one upcoming pick.
- **Highlight duration**: keep it visible for a few seconds or until the current turn resolves, whichever is simpler to implement cleanly — either is acceptable as long as the player has a fair chance to see and act on it.
- **Discounted scoring**: mark the highlighted card as "telepathy-flagged." Whenever that specific card is eventually matched (whether the player acts on the highlight right away or it gets matched some other way later), award that match via `ScoreController.recordMatch(secondsRemaining, { multiplier: 0.5 })` instead of the normal full-value call. Clear the flag once consumed.
- **Edge case**: if the flagged card happens to get matched through some other mechanism before the highlight is acted on, the 50%-points rule still applies — the discount is tied to the card, not the specific turn.

## Files touched

`src/game/powers/Telepathy.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Telepathy's entry at the real class instead of `NoOpPower`), `src/game/GameController.js` (pass-through if any extra state is needed beyond what hooks already expose), `src/game/Card.js` (highlight visual, telepathy-flag state if tracked per-card).

## Done when

- Selecting Telepathy in the 10.1 carousel and playing a game: after 3 mismatches in a row, the very next card flipped triggers a visible purple highlight on its actual match elsewhere on the board.
- Completing that highlighted match awards exactly half the normal points (base + streak bonus both halved) — verify via console-logged score math against a non-Telepathy baseline.
- The charge only triggers once per 3-mismatch streak (doesn't re-trigger on every subsequent flip until 3 more mismatches accumulate).
- Playing with a different power selected (or powers off) shows zero Telepathy behavior.
