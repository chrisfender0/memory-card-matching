# Session 10.2.2 — Power: Time Traveler

## Goal

Implement the Time Traveler power: every match adds time back to the clock, and even a bad mismatch streak grants a small time consolation.

## Depends on

Session 10 (`PowerBase`, hook call sites, `mismatchStreak`), session 10.2 (registry entry + icon already exist, plus `Timer.addSeconds(n)`).

## Spec

- **On every confirmed match** (`onMatch` hook): call `Timer.addSeconds(5)`.
- **Trigger**: `mismatchStreak` (shared tracker) reaching 3 → call `Timer.addSeconds(2)`, then reset `mismatchStreak` to 0 (so it can trigger again after another 3 consecutive mismatches).
- No scoring changes at all — this power is purely timer manipulation. Don't touch `ScoreController`.
- Respect whatever clamping `Timer.addSeconds` already enforces (from session 10.2) — don't add separate clamping logic here.

## Files touched

`src/game/powers/TimeTraveler.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Time Traveler's entry at the real class).

## Done when

- Selecting Time Traveler and playing a game: the visible countdown timer jumps up by 5 seconds on every successful match.
- Three consecutive mismatches (with no match in between) add 2 seconds to the clock, and this can trigger again after another 3-mismatch streak later in the same game.
- A single mismatch that breaks a 1- or 2-mismatch streak does not grant the 2-second bonus.
- Playing with a different power selected (or powers off) shows zero Time Traveler behavior.
