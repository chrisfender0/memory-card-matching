# Session 10.2.3 — Power: Luck of the Draw

## Goal

Implement Luck of the Draw: random flips occasionally auto-complete a match, and an extended bad streak deals extra pairs onto the board.

## Depends on

Session 10 (`PowerBase`, hook call sites, `mismatchStreak`), session 10.2 (registry entry + icon already exist, plus `Board.addPairs(n)`).

## Spec

- **On every `onFlipFirstCard`**: roll a small random chance using a named constant (e.g. `LUCK_TRIGGER_CHANCE = 0.08`). If it hits:
  - Locate the flipped card's matching partner still on the board.
  - Guard: if no partner remains face-down on the board (shouldn't normally happen, but check before acting), skip — don't crash or treat it as a match.
  - Otherwise, flip both cards face-up and run the normal match flow (session 5.4's shake/explode animation, full-value scoring via session 5.2 — no discount here) without waiting for a manual second pick. This effectively skips the "wait for second pick" turn structure for this one turn.
- **Trigger**: `mismatchStreak` (shared tracker) reaching 5 → call `Board.addPairs(2)` to inject 2 new pairs into the active board, then reset `mismatchStreak` to 0.
- Keep `LUCK_TRIGGER_CHANCE` easy to bump up temporarily during manual testing (e.g. to 0.5) so the auto-match path can actually be observed without excessive play time — revert to the real value before calling the session done.

## Files touched

`src/game/powers/LuckOfTheDraw.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Luck of the Draw's entry at the real class).

## Done when

- Selecting Luck of the Draw and playing with the trigger chance temporarily raised: flipping a first card occasionally auto-matches it with its partner immediately, playing the normal match animation and awarding full points.
- With the chance restored to its real (low) value, normal play mostly proceeds as an ordinary game.
- 5 consecutive mismatches (no match in between) correctly injects 2 new face-down pairs into the board, with the grid correctly re-laid-out and playable (no overlapping/clipped cards), and this can trigger again later in the same game after another 5-mismatch streak.
- Playing with a different power selected (or powers off) shows zero Luck of the Draw behavior.
