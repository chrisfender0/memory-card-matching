# Session 10.2.4 — Power: Cold as Ice

## Goal

Implement Cold as Ice: after 3 mismatches, the next flipped card freezes face-up until matched, escalating to a second frozen card if it's ignored too long.

## Depends on

Session 10 (`PowerBase`, hook call sites, `mismatchStreak`), session 10.2 (registry entry + icon already exist, plus the `Card.frozen` flag and the board/controller support for skipping frozen cards during mismatch flip-back).

## Spec

- **Trigger**: `mismatchStreak` (shared tracker) reaching 3 → arm `coldCharged = true` and reset `mismatchStreak` to 0.
- **Effect**: on the next `onFlipFirstCard` while charged, set that card's `frozen = true` and consume the charge. A frozen card stays face-up permanently (skips the normal mismatch flip-back timer entirely) but remains clickable/targetable for matching like any other face-up card.
- **Escalation tracking**: once a card is frozen, track `turnsSinceFreeze = 0` for it, incrementing by 1 on every subsequent `onTurnResolved` while it remains unmatched. If `turnsSinceFreeze` exceeds 3 turns without that frozen card being matched, freeze one additional random still-face-down, unmatched card (`frozen = true`) as well — this second freeze does not consume a new charge or require another 3-mismatch streak, it's a direct escalation of the first freeze.
- **Clearing**: once a frozen card is matched, it drops out of the "frozen tracking" set (normal match flow — scoring unaffected, this power only ever changes visibility/flip-back timing, never points).
- Multiple independent freezes (e.g. one from the original charge, one from escalation) should each be tracked so their own "matched" state clears correctly without interfering with each other.

## Files touched

`src/game/powers/ColdAsIce.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Cold as Ice's entry at the real class), `src/game/Card.js` (frozen flag if not already fully wired in 10.2), `src/game/GameController.js`/`Board.js` (ensure frozen cards are actually skipped during mismatch resolution).

## Done when

- Selecting Cold as Ice and playing: after 3 mismatches in a row, the next flipped card stays face-up permanently instead of flipping back down on a mismatch.
- If that frozen card isn't matched within 3 more turns, a second random unmatched card also freezes face-up.
- Frozen cards are correctly excluded from the normal mismatch auto-flip-back behavior, and matching a frozen card correctly removes it from play with normal scoring.
- Playing with a different power selected (or powers off) shows zero Cold as Ice behavior.
