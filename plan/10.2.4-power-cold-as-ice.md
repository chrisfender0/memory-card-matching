# Session 10.2.4 — Power: Cold as Ice

## Goal

Implement Cold as Ice: while no card is frozen, every 3rd move freezes a random card face-up (only one at a time). If it sits unmatched, further face-down cards lock every 3 moves after that, stacking indefinitely until a match clears the ice.

## Depends on

Session 10 (`PowerBase`, hook call sites), session 10.2 (registry entry + icon already exist, plus the `Card.frozen` flag and the board/controller support for skipping frozen cards during mismatch flip-back).

## Spec

- **Trigger**: only one card may be frozen face-up at a time. The 3-move countdown to the next freeze only runs while nothing is currently frozen — it starts (or restarts) from the move count at which the board last had zero frozen cards (game start counts as move 0). Once `moves` reaches that mark + 3, pick a random still-face-down, unmatched, unlocked card and freeze it (`card.setFrozen(true)`, flipped face-up).
- **Effect**: a frozen card stays face-up permanently (skips the normal mismatch flip-back timer entirely) but remains clickable/targetable for matching like any other face-up card.
- **Escalation**: while a card is frozen and still unmatched, every 3 more moves (3, 6, 9... after the freeze) locks one additional random still-face-down card — excluding the frozen card's own match partner, so it always stays matchable — via `card.setIceLocked(true)`. A locked card can't be selected at all while locked. Unlike the freeze itself, locks are **not** capped at one — they keep stacking every 3 moves for as long as the frozen card goes unmatched.
- **Clearing**: any match (the frozen card's own match or a completely unrelated one) clears every currently active face-down lock. Matching the frozen card itself also clears it and restarts the freeze countdown from that move. Scoring is unaffected — this power never changes points, only visibility/selectability.

## Files touched

`src/game/powers/ColdAsIce.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Cold as Ice's entry at the real class, updated description copy), `src/game/Card.js` (`frozen` flag plus a new `iceLocked` flag/`setIceLocked` for the face-down lock), `src/game/GameController.js` (skip frozen cards during mismatch flip-back; block selecting `iceLocked` cards).

## Done when

- Selecting Cold as Ice and playing: on move 3 (counting from game start, or from whenever the board was last free of a frozen card), a random face-down card flips up and stays face-up permanently instead of flipping back down on a mismatch.
- Only one card is ever frozen face-up at a time — no new freeze fires while one is already active.
- If the frozen card isn't matched, an additional random face-down card (never the frozen card's own match) becomes unselectable every 3 moves after the freeze, and these locks can stack up (more than one at once) the longer it goes unmatched.
- Any match — the frozen card's or an unrelated one — clears all active face-down locks; matching the frozen card also re-arms the 3-move countdown for the next freeze.
- Playing with a different power selected (or powers off) shows zero Cold as Ice behavior.
