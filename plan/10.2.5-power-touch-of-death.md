# Session 10.2.5 — Power: Touch of Death

## Goal

Implement Touch of Death: a card mismatched twice auto-matches with its real partner, but overusing this ability instantly loses the game with zero points.

## Depends on

Session 10 (`PowerBase`, hook call sites, `cardMismatchCounts`), session 10.2 (registry entry + icon already exist, plus the forced-loss path on `GameController`).

## Spec

- **Trigger**: using the shared `cardMismatchCounts` tracker (from session 10 — increments per card on every mismatch it's part of), watch for any single card's count reaching 2. When it does, immediately force-match that card with its real partner (auto-reveal the partner if needed, run the normal match flow) regardless of what it was actually paired with on the flip that caused this.
- **Scoring on trigger**: the touch-of-death auto-match itself still awards normal match points via the usual scoring flow — unless the instant-loss condition below fires in the same instant, in which case the loss overrides and final score becomes 0 regardless.
- **Tracking for the loss condition**: maintain `touchOfDeathCount` (total invocations this game) and `lastTurnWasTouchOfDeath` (whether the immediately preceding turn also invoked touch of death).
- **Instant loss**: if touch of death triggers twice **back-to-back** (this turn and the immediately preceding turn both invoked it), OR if `touchOfDeathCount` reaches 3 total in the game (regardless of spacing between them), immediately end the game as a loss via the shared forced-loss path from session 10.2 — locks input, sets final score to 0, routes to the game-over/leaderboard flow.
- Update `lastTurnWasTouchOfDeath` at the end of every turn (true if this turn invoked touch of death, false otherwise) so the back-to-back check stays accurate turn over turn.

## Files touched

`src/game/powers/TouchOfDeath.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Touch of Death's entry at the real class), `src/game/GameController.js` (wiring the forced-loss call if any extra glue is needed beyond what session 10.2 already built).

## Done when

- Selecting Touch of Death and playing: mismatching the same specific card a second time (i.e. its second time being part of a mismatch) automatically matches it with its real partner and awards normal points.
- Triggering this ability in two consecutive turns instantly ends the game with score forced to 0.
- Triggering this ability a 3rd time total in a single game (even with normal turns in between) also instantly ends the game with score forced to 0.
- Triggering it once, or twice with a normal turn in between (not back-to-back, and not yet a 3rd total), does not end the game.
- Playing with a different power selected (or powers off) shows zero Touch of Death behavior.
