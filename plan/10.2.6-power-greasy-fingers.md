# Session 10.2.6 — Power: Greasy Fingers

## Goal

Implement Greasy Fingers: matching a pair sometimes triggers a brief peek at another random card, with a cooldown so it can't chain endlessly.

## Depends on

Session 10 (`PowerBase`, hook call sites), session 10.2 (registry entry + icon already exist).

## Spec

- **On every confirmed match** (`onMatch` hook), if not currently on cooldown, roll a chance using a named constant (e.g. `GREASY_TRIGGER_CHANCE = 0.25`). If it hits:
  - Randomly pick another face-down, unmatched card still on the board.
  - Flip it face-up temporarily for 1 second, then flip it back face-down automatically.
  - This is a pure information bonus — no scoring or persistent state change from the peek itself.
- **Cooldown**: once a peek triggers, set `greasyOnCooldown = true`. It cannot trigger again until the *next* successful match happens — clear the cooldown flag at the start of the match-check for that next match (before rolling the chance again), so at most one peek can occur per "eligible" match, and a match immediately following a peek-triggering match is guaranteed not to peek (cooldown still set going into it), with normal rolling resuming from the match after that.
- **Non-interference**: make sure the temporary 1-second peek doesn't interfere with the mismatch/match lock state from sessions 5/5.4 — treat it as a purely visual aside that runs independently and doesn't hold up or block normal turn progression (the player should be able to keep flipping cards normally while a peek is mid-animation, unless that conflicts with existing lock behavior, in which case queue the peek to run right after the current lock clears rather than block on it).

## Files touched

`src/game/powers/GreasyFingers.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Greasy Fingers's entry at the real class).

## Done when

- Selecting Greasy Fingers and playing (temporarily raising `GREASY_TRIGGER_CHANCE` for testing if needed): matching a pair occasionally triggers a different random card flipping face-up for about 1 second, then flipping back down on its own, with no effect on score or match state.
- Two matches in a row never both trigger a peek — if one match triggers it, the very next match is guaranteed not to (cooldown enforced), with normal rolling resuming afterward.
- The peek animation never blocks or breaks normal card-flipping/turn progression.
- Playing with a different power selected (or powers off) shows zero Greasy Fingers behavior.
