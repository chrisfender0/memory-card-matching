# Session 10.2.7 — Power: Battery Powered

## Goal

Implement Battery Powered: tapping your already-face-up first-pick card again supercharges it — a supercharged match pays double, a supercharged mismatch costs 50 points.

## Depends on

Session 10 (`PowerBase`, hook call sites), session 10.2 (registry entry + icon, the `onRepeatTapFirstPick` hook, `Card.armedTag`, `ScoreController.deductPoints`).

## Spec

- **Arming**: while a card is the current turn's first pick (face-up, unmatched, awaiting a second pick), tapping that same card again fires `onRepeatTapFirstPick(card, ctx)`. Set `card.armedTag = 'supercharged'` and give it a distinct visual treatment (glow/spark effect) so the player can tell it's charged.
- Only the current first-pick card can be supercharged — tapping any other (face-down) card proceeds as a normal second pick, whether or not the first card was charged.
- **Resolution**:
  - If the turn resolves as a **match** and the first-pick card was supercharged: award **2× normal points** for that match (base + streak bonus both doubled) via the existing `ScoreController.recordMatch(secondsRemaining, { multiplier: 2 })`.
  - If the turn resolves as a **mismatch** and the first-pick card was supercharged: call `ScoreController.deductPoints(50)` in addition to the normal mismatch handling (streak reset, mismatch counters, etc. — all unaffected, this power only changes points).
  - If the first-pick card was never supercharged, resolve entirely normally (no multiplier, no deduction).
- Clear `armedTag` once the turn resolves either way (charge doesn't carry over to the next turn).

## Files touched

`src/game/powers/BatteryPowered.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point Battery Powered's entry at the real class).

## Done when

- Selecting Battery Powered and playing: tapping the current face-up first-pick card a second time visibly supercharges it (distinct visual state).
- Completing a match with the first-pick card supercharged awards exactly double the normal points for that match.
- Completing a mismatch with the first-pick card supercharged deducts exactly 50 points (clamped at 0 if the running score is below 50).
- Turns where the first-pick card was never supercharged behave with completely normal scoring.
- Playing with a different power selected (or powers off) shows zero Battery Powered behavior.
