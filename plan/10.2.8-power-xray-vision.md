# Session 10.2.8 — Power: X-ray Vision

## Goal

Implement X-ray Vision: a 2-charge HUD button that briefly reveals the whole board, with escalating penalties for mismatching afterward — worse the second time it's used.

## Depends on

Session 10 (`PowerBase`, hook call sites), session 10.2 (registry entry + icon, `Board.peekAll(durationMs)`, `Board.burnRandomPair`, `ScoreController.deductPoints`, `Timer.addSeconds`, `PowerChargeButton`).

## Spec

- **Button**: mount a `PowerChargeButton` (session 10.2) in the HUD with 2 charges, wired so `onActivate()` calls `Board.peekAll(500)` — flashes every eligible face-down card face-up for half a second, then back down.
- **Penalty tracking after use 1**: once the first charge is used, start counting mismatches from that point (`mismatchesSinceFirstXray`, independent from the shared `mismatchStreak`). When it reaches **3**, trigger the use-1 penalty: `Board.burnRandomPair({ scoreMultiplier: 0 })` (burn a random pair for no points) and `Timer.addSeconds(-10)`. After the penalty fires, stop counting for this arm (it's spent — a fresh countdown only starts again if/when the second charge is used).
- **Penalty tracking after use 2**: once the second (final) charge is used, the very **next mismatch** (just 1, not 3 — this use is harsher) triggers the use-2 penalty: `Board.burnRandomPair({ scoreMultiplier: 0 })`, `Timer.addSeconds(-20)`, and `ScoreController.deductPoints(100)`.
- Only one penalty countdown is ever "live" at a time — using charge 2 while a use-1 countdown is still pending replaces it with the harsher use-2 countdown (the milder one never fires once the second charge is spent).
- No penalty at all if the player never mismatches after a use (e.g. wins outright, or only ever matches afterward) — the countdown simply never reaches its trigger point.
- Peeking itself has no effect on score, moves, or the timer — only the escalating post-use mismatch penalties do.

## Files touched

`src/game/powers/XrayVision.js` (new, extends `PowerBase`), `src/game/powers/registry.js` (point X-ray Vision's entry at the real class), `src/ui/HUD.js` or equivalent (mount the `PowerChargeButton`).

## Done when

- Selecting X-ray Vision: the HUD button shows 2/2 charges; activating it flashes the whole board face-up for ~0.5s then back down, and decrements to 1/2.
- After the first use, exactly the 3rd subsequent mismatch burns a random pair (awarding no points for it, still counting toward win completion) and removes 10 seconds from the clock; earlier mismatches (1st, 2nd) do nothing.
- After the second (final) use, the very next mismatch burns a random pair, removes 20 seconds, and deducts 100 points — no 3-mismatch grace period this time.
- The button disables itself at 0 charges remaining.
- Playing with a different power selected (or powers off) shows zero X-ray Vision behavior.
